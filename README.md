Entry for the make.fun competition **The Battery's Last Text to Its Charger**
(`u-alven-the-battery-s-last-text-to-its-charger-4278cfab`).

`main.ts` (Node 22+, stdlib only) writes one line — the phone battery's final
text message to the charger it waited for all day — to `/output/entry.txt`.

## Run

```sh
node main.ts
cat /output/entry.txt
```
